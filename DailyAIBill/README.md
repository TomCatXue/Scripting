# 每日 AI 账单 · Daily AI Bill

把 [magpie](https://usemagpie.ai) 记录的 AI 用量打印成一张小票。三种尺寸：

| 尺寸 | 内容 |
|---|---|
| **2×2**（small） | 总费用、请求数/错误/连续天数、最贵的一个模型。两种变体：**模型版**（默认）与 **预算版**（参数填 `budget`） |
| **4×2**（medium） | 左栏总额 + 预算进度条 + 摘要，右栏 AGENT → 模型两级清单 |
| **4×4**（large） | 完整账单：日期时间、总额、四格统计、AGENT 两级明细带费用占比、堆叠比例条与图例、Token 明细 |

## 效果预览

`design_preview/ai_bill_widgets.html` 是按真机尺寸（158×158 / 338×158 / 338×354）做的像素级原型，
用浏览器打开即可看到三个尺寸并排对照。该目录不随仓库推送。

## 数据来源

直连本机或局域网的 magpie 网关，只用这两个只读接口：

| 接口 | 用途 |
|---|---|
| `GET /v1/magpie/usage?period=today\|7d\|30d\|all` | 总额、调用数、错误数、Token、缓存命中、agents/models 数组、日桶序列 |
| `GET /v1/magpie/usage/requests?limit=500&offset=N&period=...` | 逐条明细，用于还原 **AGENT → 模型** 的两级归属 |

接口只回 USD 数值，**不含汇率**，所以汇率在设置里手填。

## 配置

### 1. 在电脑上生成只读 Key

```sh
magpie gateway-key add alma-widget --read-only
```

会打印一串 key。只读 key 仅能读用量与配额，不能调用模型、不能改任何配置。

### 2. 填网关地址

- **同一台电脑**：`http://127.0.0.1:3425`（本机访问不需 key）
- **手机 / 其他电脑**：`http://<这台电脑的局域网 IP>:3425`，例如 `http://192.168.0.149:3425`

不写 `http://` 会自动补。

### 3. 设置页里的其他项

- **汇率**：`1 USD = ? CNY`，默认 `6.67`（2026-11 实测值）
- **每日预算**：填 `0` 表示不显示进度条
- **统计周期**：今天 / 近 7 天 / 近 30 天 / 全部

## 已知边界

1. **AGENT → 模型 的归属要自己算。** HTTP 接口只给平行的 `agents[]` 和 `models[]`，没有“这个模型属于哪个 agent”的字段。所以靠拉 rows 自行聚合。
2. **历史周期只有扁平数据。** rows 用 `limit=500` + `offset` 翻页，但 7 天就有 6000+ 条、30 天 25000+ 条。超过 3000 条时自动放弃两级结构，改用 `/usage` 的准确 `agents` 总量，并在表头标注“（仅总量）”。**今天的数据永远是精确的。**
3. **连续使用天数**要“每天是否有调用”，today 的分桶是 24 个小时桶算不出来，所以额外拉一次 `all` 拿日桶序列。多一次请求，失败也不影响主数据。
4. **刷新间隔约 15 分钟**，受 iOS 限制。点小组件可立即刷新（AppIntent）。
5. **明文 HTTP**：局域网内可用，跨公网建议配 Tailscale 或 Cloudflare Tunnel，然后在设置里改成对应地址即可，代码无需改动。

## 设计要点

小票质感靠三件事，不是靠配色：

- **纸张底色** `#FBF9F3`，带一点暖黄，不是纯白
- **全部数字走等宽字体**（`fontDesign="monospaced"`），保证金额和小数点对齐
- **分隔线用 1px 实色** `#DEDACC`，不用半透明——半透明叠在不同底色上会变色

大写的 AGENT 名与参考图一致；模型名在 4×2 里会被缩写（`deepseek-v4.1-flash` → `DEEPSEEK-V4.1`），否则会顶掉右侧金额。
